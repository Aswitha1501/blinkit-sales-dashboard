# Blinkit Sales Dashboard

Power BI dashboard analyzing Blinkit-style retail sales data to understand sales across outlets, products, and locations.

![Dashboard](Screenshot%202026-06-22%20112406.png)

## Tools Used
- Power BI

## Dataset
BigMart sales dataset, used to build a Blinkit-style retail analytics dashboard.

## Dashboard Includes
- KPI cards: Total Sales, Average Sales, Number of Items, Average MRP
- Sales by Fat Content, Item Type, Outlet Size, Outlet Location, and Outlet Type
- Sales trend by outlet establishment year
- Slicers for Outlet Location Type, Outlet Size, and Item Type

## Key Insights
- Tier 3 outlets contribute the highest sales
- Supermarket Type 1 generates the highest revenue
- Low Fat products contribute more sales than Regular products
